# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
Please report sensitive security issues directly to security@mymausam.org rather than public GitHub issues.
We aim to acknowledge reports within 48 hours and provide patches promptly.
