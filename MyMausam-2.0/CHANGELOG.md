# Changelog

All notable changes to **MyMausam 2.0** will be documented in this file.

## [2.0.0] - 2026-08-28
### Added
- Complete Next.js 16 App Router interface with glassmorphism UI design.
- AI Personalization Engine with 8 Persona modes (Health, Runner, Farmer, Commuter, Traveler, Family, Beach, Event Planner).
- 18 feature routes: Doppler Radar, Lightning nowcast, Cyclone tracking, Aviation METAR, Agromet bulletins, Route nowcast, Rain timeline, Solar estimator.
- Python FastAPI backend with SQLite persistence (`mausam.db`).
- Monorepo structure with Turborepo and pnpm workspaces.
