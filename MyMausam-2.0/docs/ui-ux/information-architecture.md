# Information Architecture — MyMausam 2.0

## Site Map

```
/ (Home — Current Weather Dashboard)
├── /forecast          (7-Day Extended Forecast)
├── /radar             (Doppler Radar Map)
├── /alerts            (Emergency Weather Warnings)
├── /rain-alert        (2-Hour Rain Nowcast)
├── /cyclone           (Cyclone Tracker)
├── /lightning         (Lightning Strike Map)
├── /aviation          (METAR / TAF Aerodrome Weather)
├── /agromet           (Agriculture & Crop Advisories)
├── /marine            (Marine & Sea State Forecast)
├── /route-nowcast     (Highway Route Weather)
├── /solar-estimator   (Rooftop Solar PV Calculator)
├── /health-index      (AQI & Health Risk Index)
├── /chat              (MausamMitra WeatherGPT)
├── /crowd-source      (Crowdsourced Weather Reports)
├── /activity-planner  (Outdoor Activity Planner)
├── /favourites        (Saved Locations)
├── /notifications     (Alert Notification Settings)
└── /settings          (Units, Language, Accessibility)
```

## Navigation Hierarchy
- **Primary Nav**: Forecast, Radar, Alerts, Solar — always visible in top navigation bar.
- **Secondary Nav**: Sector-specific features (Aviation, Marine, Agromet) in a "Sectors" dropdown.
- **Utility Nav**: Chat, Notifications, Settings, Profile in header right side.

## Search
Global city search accessible via `Ctrl+K` shortcut anywhere in the app.
