# ML Architecture

Three predictive ML pipelines:
1. **Solar Irradiance (GHI/DNI)**: XGBoost regressor predicting rooftop PV yield based on solar zenith, cloud cover, and humidity.
2. **Grid Demand Forecaster**: Random Forest regressor for off-peak consumption windows.
3. **Personalization Engine**: Mission LiFE persona weighting model prioritizing widgets and alerts.
